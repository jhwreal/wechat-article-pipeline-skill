# 今日头条 Browser Subagent（内置浏览器）发布流程

发布前按 [自动检查与隐藏记录](pre-publish-check.md) 处理：用户未明确跳过且当前稿无有效检查时，自动检查并在对话中报告结果；无待决定的内容问题就继续本次授权流程，不询问是否开始检查。草稿、立即/定时发布均适用，同篇同版跨平台复用结果。

## 适用边界与互斥守卫

- **仅当当前 Agent 运行时不具备操作真实前台应用的 Computer Use，但具备内置浏览器 / Browser Subagent（如 Antigravity）时使用本流程。**
- 如果当前运行时具备真实前台应用 Computer Use（如 Codex 的原生 Computer Use 或 `@oai/sky`），**必须返回 [publishing-toutiao.md](publishing-toutiao.md)**，严禁使用本文件，严禁混用 Computer Use 与浏览器自动化。
- 如果运行时既无 Computer Use 也无浏览器能力，降级为本地工作台交付，由用户手工复制粘贴。
- 本流程严格禁止调用私有的未公开 HTTP 接口、提取 Cookie/Token 重放请求或绕过登录/CAPTCHA。微信草稿箱的“只用官方 API”限制仍只适用于 `mp.weixin.qq.com`。

## 发布授权：明确指令即确认

完整继承 [publishing-toutiao.md](publishing-toutiao.md) 的发布授权口径：

- 用户在本人消息中明确说“发头条”“发布头条”“头条定时发布”，或给出“头条明天 7:30 发布”这类目的地、发布方式和时间明确的指令时，该指令本身就是本次头条发布的确认和授权。
- 同一内容、同一头条账号、同一发布时间的流程里，不得在填写标题、粘贴正文、进入预览、点击最终发布或定时发布前再次询问“是否确认发布”“要不要继续”或同义问题。
- 只有在会实质改变用户授权的目标、内容、账号、发布时间或可见范围仍缺失或发生变化时，才询问对应缺口。
- 登录失效、扫码登录、CAPTCHA、平台强制管理员确认或其他硬阻断，必须立即暂停，请用户在内置浏览器窗格手动完成后再恢复同一会话，绝不尝试绕过。

## 权威内容与平台规则

完整继承 [publishing-toutiao.md](publishing-toutiao.md) 的内容与发布选项规则：

- 以用户确认的最终 Markdown / 本地工作台正文为准，不从旧头条草稿反向覆盖本地稿。
- 标题直接读取 Markdown 第一个 H1；超过 30 字时使用独立的头条短标题，不改 Markdown 总标题或公众号标题。正文不得重复文章标题、公众号原创篇号或微信专属签名。
- 来源名称保留纯文本，正文外部 `<a href>` 数量必须为 0。
- 封面默认选择“单图”并选用正文第一张图片，确认缩略图出现且与首图一致。
- 跨平台同步默认关闭 `头条首发`；仅用户确认符合独家/时限规则时开启。
- 广告收益默认选择 `投放广告赚收益`；仅用户明确要求不挂广告时选择 `不投放广告`。读取实际单选框 `checked` 状态；两个选项都未选中时不得保存草稿或提交。结果文件记录 `toutiao_ads_enabled: true|false`。

## 内置浏览器端到端执行顺序

先识别实际后端，结果文件记录 `browser_backend`。Antigravity App 单标签后端记录 `built-in`；先只读检查目标账号、登录态和空编辑器，再在子代理自己的同一标签打开工作台。复制成功后在同一标签重新导航到平台入口，再次确认账号和空编辑器。支持标签切换的 Chrome 后端记录 `chrome-devtools`，可以保留编辑器标签，另开工作台标签复制后切回。复制后填写标题时使用直接输入，保持富文本剪贴板内容。浏览器权限受限时遵循当前后端的接管流程；若无法执行富文本粘贴或读回规定证据，交付工作台和已知状态供人工核验。

在第一次向头条编辑器写入前，先启动或确认本地工作台服务可达（`http://127.0.0.1:<port>/files/<slug>.html`），并记录：Markdown 第一个 H1、必要时的头条短标题（≤30 字）、投放方式、封面模式、是否首发、发布方式、北京时间和预期图片数。

1. **检查登录态与干净发布页**：
   - 在内置浏览器中打开 `https://mp.toutiao.com/profile_v4/graphic/publish`。
   - 若跳转至登录页（如 `mp.toutiao.com/auth/page/login`）或出现验证码，立即暂停并提示用户在内置浏览器窗格完成登录；用户确认后在同一 browser subagent 会话中继续。
   - 确认进入的是干净发布页（标题为空、正文为空）。若编辑区已有来源不明的旧稿，立即停止，不得覆盖。
2. **工作台一次复制（唯一正文入口）**：
   - 按上述后端规则打开本地工作台 URL，切换顶部平台下拉框为 `头条格式`（`toutiao`）。
   - 确认复制前检查无阻断项，点击一次主复制按钮 `复制为头条格式`。
   - 状态栏须显示“已复制今日头条格式”。预期 0 张时核对“无正文图片”；有图时核对实际 N 张图片及托管回执或 `embedded-data` 模式。
3. **头条编辑器一次粘贴**：
   - 按后端路径返回并确认头条干净发布页，填入标题（≤30 字）。
   - 点击聚焦 `.ProseMirror` 正文编辑区，执行一次真实粘贴快捷键（macOS 使用 `Meta+v` / Cmd+V，其他系统使用 `Control+v`）。
   - 立即进入 `PASTE_PENDING`，最多等待 15 秒让富文本与内嵌图片异步上传为头条托管图；等待期间只做只读观测，禁止再次粘贴。
   - 若单次粘贴失败或等待 15 秒后仍为空，保留该干净页作为诊断现场并停止，不逐段重写正文、不改走单图上传按钮替代整篇粘贴。
4. **只读结构与图片硬门槛核验**：
   - 核验首段、至少两个正文哨兵句与末段完整且顺序正确，字数合理。
   - 核验标题 DOM：`<h1>` 数量与文本顺序与 Markdown 正文各级小标题一致，`<h2>`/`<h3>` 为 0；引用块与加粗保留正常。
   - 核验外链：正文内外部 `<a href>` 数量为 0。
   - 核验图片上传与托管域名（**去重规则**）：头条 `.ProseMirror` DOM 可能伴随 `src=null` 且尺寸为 `0x0` 的辅助 `<img>` 占位节点；核验时只统计具备有效头条托管域名（如 `toutiao.com` / `toutiaoimg.com` / `pstatp.com`）且渲染尺寸 `> 0` 的唯一可见图片，确认其数量等于预期图片数，首图、中图、尾图位置正确，且无残留 `data:`、`blob:`、`file:` 或 `127.0.0.1`。
5. **设置发布选项与保存/提交**：
   - 如有正文首图则默认单图封面；无正文图片时按已授权的封面选项操作，平台要求另选素材时先停下。按已记录的广告和首发选择设置并读回。
   - 用户只要求同步草稿时，确认草稿保存成功并核验标题后即止，不进入发布。
   - 用户明确要求立即发布或定时发布时，必须确认当前账号、封面、广告、作品声明和首发选项，检查作品管理页当天没有同标题有效稿，并确认本次提交锁未使用；按原流程逐项通过[提交前硬门槛](publishing-toutiao.md#提交前硬门槛)，并严格执行定时发布入口白名单与单次提交熔断。

## 定时发布入口白名单、状态机与单次提交熔断

完整沿用 [publishing-toutiao.md](publishing-toutiao.md) 的安全机制作用于内置浏览器：

- **定时发布入口白名单**：底部存在 `预览`、`定时发布`、`预览并发布` 三个相邻按钮；定时任务第一次入口只能点击文字精确等于 `定时发布` 的按钮，严禁点击 `预览并发布` 或 `发布`。点击后必须重新确认定时对话框与时间输入区出现，逐字符读回完整北京时间（与用户指定绝对时间完全一致），再依次只点一次 `预览并定时发布` → 最终预览页 `定时发布`。
- **五态状态机**：严格按 `EDITOR_READY` → `TIME_DIALOG` → `TIME_CONFIRMED` → `FINAL_PREVIEW` → `MANAGEMENT_VERIFY` 推进，不得合并步骤。管理页先显示 `审核中` 属正常中间状态，不得据此删除或重发；审核后出现 `将于 MM-DD HH:mm 发布` 再核对一致。
- **单次提交熔断与一次性恢复**：
  - 点击最终发布/定时发布瞬间将 `submission_maybe_sent` 置为 `true` 并冻结所有写操作；超时或未跳转时只到作品管理页按精确标题只读核验，绝对禁止二次点击。
  - 仅在用户明确授权“删掉重发”后，允许最多一次恢复事务（`recovery_attempts_used` 持久化为 `1`），先精确按 `pgc_id` 删除错误行并核验消失，再决定是否重新提交。
- **发布后验收**：立即发布在作品管理页变为 `已发布` 后打开公开页，滚动确认懒加载图片、首末段、标题和后记均完整可见。

## 可审计结果记录

每次同步在 `<workspace>/files/<slug>.toutiao-result.json` 中记录：

- `ui_driver`: 固定为 `browser-subagent`
- `browser_backend`、`clipboard_path`（记录实际后端与剪贴板路径）
- `clipboard_strategy`: 按工作台实际回执记录（如 `native-selection` 或 `clipboard-html`）；读不到时标为未知
- `delivery_source_fingerprint`: 本轮三平台/文章源指纹
- `title`、必要时的 `toutiao_short_title`、`mode`（`draft` / `publish` / `schedule`）
- `expected_images`、`verified_images`、`expected_h1`、`verified_h1`、`external_links`
- `toutiao_ads_enabled: true|false`、`toutiao_exclusive_enabled: false|true`
- 定时路径审计字段：入口前看到的全部底部按钮、`schedule_entry_clicked`、用户要求绝对时间、读回绝对时间、最终按钮文字
- `draft_verified`、`submission_maybe_sent`、`pgc_id`、`management_status`、`public_url`
- 恢复字段（若发生）：`recovery_attempts_used`、`deletion_verified`、`replacement_submitted`
