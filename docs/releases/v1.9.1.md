# v1.9.1：修复审核问题并完善变更追踪

发布日期：2026-09-21。基于 `v1.9.0` 的维护发布，保留“检查”/“检查一下”触发的五项检查模式：错别字、重要事实、结构与主题、对象感、优化建议。本次修复整体审核发现的 9 类问题，并整理工作台模块。

## 问题与修改

| 编号 | 原有问题 | 本次修复 |
| --- | --- | --- |
| A01 | 同一服务可能处理其他文章的保存请求 | HTTP 入口绑定文章，保存和图片上传核对文章身份 |
| A02 | 旧缓存或另一服务的旧版本可能覆盖新稿 | 校验文章、版本和指纹；保存时在文件锁内重读状态；冲突稿保留供复制对照 |
| A03 | token 缓存可能复用其他 AppID 的令牌 | 缓存按实际 AppID 定位并核验归属；无归属的旧缓存重新获取 |
| A04 | 微信转换时丢失列表续行或嵌套内容 | 保留文字与子项，Python 与浏览器用 7 组共享样例核对内容 |
| A05 | 图片数量不变时可能使用旧托管地址 | 回执绑定正文、图片内容和顺序；旧回执失效时回退内嵌图片；回执写回与保存共用锁 |
| A06 | 过期发布清单可能创建旧内容草稿 | dry-run 与新建入口核对最新任务和工作台状态；已创建草稿的恢复仍沿用原运行快照 |
| A07 | 改稿沿用旧平台成功状态，验收计数矛盾也可能通过 | 状态绑定文章版本，归档历史；验证实际草稿及图片、标题数量；保留未知提交状态直至确认 |
| A08 | 同篇修订用总篇号减一，交错写文章时会取错 | 从文章自身保存的签名读取篇号，并核验文章、账号及当前计数 |
| A09 | 标题含反斜杠或替换语法时构建、保存异常 | 按字面替换标题，正确转义 HTML 特殊字符 |

另外，文章模型从 HTTP 服务中独立出来，Markdown 解析模块单独维护并在打包时内嵌；候选发布清单按服务实例隔离。检查报告增加原文指纹、检查时间及可用的工作台版本；新增 6 组明确标为人工验收素材的检查模式案例。

## 升级与兼容性

- 同步技能发布文件，保留本机 `.env`、篇号、账号凭据和缓存；运行 `doctor_wechat_article_skill.py --require-installed-sync`。
- 旧工作台从原 Markdown/job 重新打包后编辑。无法验证来源的旧浏览器缓存作为对照保留，不能直接当作最新稿。
- 无来源绑定的旧图片回执需要重新获取；旧发布清单核验不过时重新生成。头条缺少有效托管回执时会回退到内嵌原图；原图读取失败时才停止复制。粘贴后仍需核验目标平台图片已上传。
- 旧三平台状态执行 `init` 后保留在 `history`；无法确认是否已提交的记录必须先核实，不能直接重置再投递。
- 同篇改稿若缺少原有篇号签名，应恢复真实文章记录；不能通过倒推或调低账号总篇号补造。
