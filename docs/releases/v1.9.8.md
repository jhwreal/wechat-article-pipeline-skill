# v1.9.8 跨 Agent 公众号配置与小红书草稿核验

发布于 2026-11-25，基于 v1.9.7。

## 行为变化

- 从源码加载 skill 的 Antigravity 与使用安装副本的 Codex 可以通过工作区里的 `.local/wechat-publisher-env.path` 读取同一份公众号配置。配置路径失效时会报错，避免在不同入口生成不同署名或篇号。
- 头条和小红书分别说明桌面单标签与可切换标签的 Chrome 后端如何交接富文本。工作台显示“无正文图片”时，预期无图的稿件可以继续。
- 小红书图片按完整托管地址、正文顺序和位置核验，报告实测数量及缺失位置。浏览器子代理保存草稿后，须从列表重新打开并核对正文、标题和图片，才能登记为已验证。
- 公开提交前核对授权模式、账号和可见范围。定时发布还需读回完整北京时间；缺失或不一致时保留草稿。

## 验证范围

243 项 Python 测试和 58 项 JavaScript 测试覆盖配置绑定、零图复制、同一 CDN 的多图核验、草稿回读及提交设置等行为。真实小红书创作者后台的跨站粘贴、暂存及重开仍待实测。

## 升级与回退

按 README 同步技能文件并运行 `doctor_wechat_article_skill.py --require-installed-sync`。需要跨 Agent 共用配置的工作区可把已有环境文件的路径写入本机绑定文件。回退时可在独立检出目录从 v1.9.7 重新同步技能文件，保留本机账号、篇号与文章。
