# v1.9.3：上传前自动检查，避免无反馈等待

发布日期：2026-10-04。基于 v1.9.2 的补丁发布。

## 问题与修改

旧规则在当前稿没有有效检查记录时要求询问“先检查还是跳过”并等待，导致用户已经要求上传却看不到实际进展。

现在用户未明确跳过检查时，Agent 自动检查最新稿、保存报告并在当前对话反馈结果。没有待处理问题或只有可选润色时继续原授权上传；已确认的错字、重大事实错误及影响核心判断的证据缺口会列出原句、改法和上传状态。有改稿授权就修改复核后继续，否则只询问具体取舍。不会为了开始检查而额外等待，也不会静默改写用户正文。

明确跳过仅适用于本次同篇同版；已检查版本可复用，修改后重新判断。检查记录损坏时仍执行实际检查并保留证据，不把技术记账故障当成已检查或原地停止的理由。平台安全阻断与单次提交规则保持有效。

统一更新 Skill 入口、发布前参考、四个平台发布流程、检查模式及中英文 README；更新行为验收素材。底层 API 与检查记录脚本没有新增自动内容审查能力，自动检查由使用 Skill 的 Agent 执行。
