# v1.9.6：微信复制排除文章总标题

发布日期：2026-11-05。基于 v1.9.5 的补丁发布。

## 问题与修改

点击“复制为微信格式”时，文章总标题会和正文一起进入剪贴板，粘贴到公众号正文后出现重复标题。

- 微信剪贴板输出移除第一个 Markdown H1，从开头题图开始；没有题图时保留标题后的完整正文。
- 保留题图、原创篇号、正文小标题与 GIF，复制前的结构检查使用相同规则。
- 工作台预览与 Markdown 继续保留文章总标题，共用排版函数的 API 导出默认行为保持兼容；头条和小红书复制行为不变。
- 微信平台适配器版本由 1.0.0 升至 1.0.1，技能与项目版本升至 1.9.6。
- 纳入此前已在安装版生效的维护：原创篇号位于开头题图之后（无题图则标题后），正文截图不充当题图；技能入口长度上限由 1200 调整为 1500，下限仍为 800。

## 升级与回退

按 README 的排除规则同步技能，不覆盖本机 `.env`、账号配置、篇号或缓存。新生成的工作台使用新版模板；其他历史工作台需要重新打包才会更新复制行为。

回退可通过新提交 revert 本补丁，或从 v1.9.5 恢复技能发布文件后重新同步。不移动既有标签。
