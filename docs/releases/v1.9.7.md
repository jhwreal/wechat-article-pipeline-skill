# v1.9.7：修复换图重打包后的保存冲突误报

发布日期：2026-11-07。基于 v1.9.6 的补丁发布。

## 问题与修改

仅修改配图计划或图片说明时，正文和图片路径可能保持不变。旧工作台据此无法识别重新打包，仍将任务配置变化视为未处理的外部修改，阻止保存；界面又将版本冲突显示成保存服务不可用，容易导致反复重启。

- 打包时记录源任务 JSON 的规范化指纹，识别未反映在预览文字中的配置变化；保存事务同步更新指纹。
- 指纹绑定打包前的源任务，生成剪贴板资源等派生字段不影响源任务校验。
- 未重新打包的外部改动、打包后首次打开前的修改，以及重打包后的再次修改，仍阻止旧页面覆盖。
- 冲突提示明确说明保存服务仍在运行，要求保留草稿、核对源文件并重新打包；不再误导用户靠重启解决版本冲突。
- 保留旧版单文件工作台、事务恢复、重复保存不写盘等现有行为。技能与项目版本升至 1.9.7。

## 升级与回退

按 README 同步技能发布文件，保留本机 `.env`、账号配置、原创篇号和缓存。更新保存服务需重启现有进程；历史工作台需在保留并核对浏览器草稿后重新打包，才能使用新指纹和提示。

回退可通过新提交 revert 本补丁，或从 v1.9.6 恢复技能发布文件后重新同步。不移动既有标签，不清除工作台冲突保护状态。
