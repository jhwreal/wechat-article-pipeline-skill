# 检查模式行为验收

`article-check-cases.json` 是人工行为验收素材，不是自动事实核查程序。每组案例在独立测试对话中运行，将 `request`、`article` 和可选的 `context`、`evidence` 一起交给已加载本 skill 的 Agent，逐项对照 `rubric` 记录通过、失败和证据。

文件类案例只在临时项目中运行。检查前后比较原稿内容，确认“只检查”没有改稿；明确要求改稿的案例核对实际修改是否在授权范围内。事实类案例使用给定的虚构资料，不能宣称已核实真实世界事实。需要评估联网核查时，另准备可访问的原始资料并记录访问时间。

记录应注明 skill 版本、Agent 及模型、输入、输出、工具操作和未覆盖的条件。不能把这些案例已存在或 JSON 格式有效算作模型行为通过。本次自动回归测试数不包含这 6 组素材。
